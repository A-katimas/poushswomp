The objective of this project is to sort a data structure known as a stack. It consists of an array containing positive integers that are initially arranged in a random order. The main challenge is to implement algorithms that efficiently organize these data.


To use this project, you must run the ``./pushswap`` command followed by the numbers you wish to sort.
If the project has not been compiled yet or if the ``pushswap`` executable does not exist, first run the ``make`` command to generate it, then execute the previous command again.

*order to confirm:*

``make``: compilation of the project

``make test``: compilation of the project and execute random value

``make re``: project execution and recompilation

``make clean``: use of ".o" files not useful for your compilation

``make fclean``: overpressure of the generated file access


*typical type:*
``
make test
``
